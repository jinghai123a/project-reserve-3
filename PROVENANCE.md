# Public distribution

Cloud Company Kit packages a reusable cloud execution runtime, task-scoped roles,
deployment configuration, project templates and synthetic verification examples.
Project source is distributed under the Unlicense in LICENSE.

Optional tools are installed separately from pinned package or container sources.
Their package licenses and integrity metadata stay with those tools. The public
source tree contains integration code and configuration rather than installed
packages, model weights, credentials or customer workspaces.
